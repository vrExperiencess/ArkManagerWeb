# Ark Manager (ASA)

**Ark Manager (ASA)** es una interfaz web tipo dashboard (minimalista y futurista) pensada para jugadores de **ARK: Survival Ascended**, enfocada en centralizar el control de **personajes**, **bases** y (próximamente) **waypoints** en una experiencia tipo tablero.

> Objetivo: tener una vista clara y rápida de “qué tengo, dónde está, qué me falta y qué debo hacer” en uno o varios mapas/servidores.

---

## ✨ Features

### ✅ Dashboard
- Tarjetas de personajes con información clave (nombre, imagen, progreso, etc.)
- Resumen de bosses asignados (incluye bosses marcados aunque no sumen nivel)
- Estado/tiempo de decay y progreso de bases (según utilidades internas)

### ✅ Bases
- Utilidades para nombre visible, cálculo de decay, progreso, fechas estimadas, etc.

### 🧭 Waypoints (En desarrollo)
- Página placeholder indicando que el módulo está en construcción  
- La idea es incorporar un editor/gestor robusto en futuras versiones

---

## 🧱 Tech Stack
- **React + Vite**
- **TailwindCSS**
- Componentización orientada a tarjetas (DashboardCharacterCard, DashboardBaseCard, etc.)
- Helpers/Utils para lógica de personajes y bases
